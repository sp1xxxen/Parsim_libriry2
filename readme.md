# Парсим библиотеку

Проект написан для получения обложек для книг и текста.

## О проекте

В основном данный проект, используется для работы с книжным сайтом, где можно работать с каждой книгой на этом сайте.

## Как установить

Python3 должен быть уже установлен. 
Затем используйте `pip` (или `pip3`, есть конфликт с Python2) для установки зависимостей:
```
pip install -r requirements.txt
```

## Как Запустить проекта

Скачайте репозиторий с гитхаба. Загрузите репозиторий в Visual  Studio Code и запустите проект, скачав нужные библиотеки, которые описаны в начале проекта.
Для того чтобы запустить проект в терминал нужно написать 
```
python main.py
```

## Аргументы запуска
Теперь в данном проекте можно скачивать не только все сразу, а можно выбрать, что скачать, либо только картинки, либо только текст, и все вместе.
Это можно сделать если прописать:
Если вы хотите скачать только текст:
```
python main.py --skip_imgs
```
Если вы хотите скачать только картинки:
```
python main.py --skip__txt 
```
Также можно скачивать книги с определенной страницы.

Прописав в терминал:
```
python main.py --start_page (номер страницы начала) --end_page (номер страницы в конце)
```
